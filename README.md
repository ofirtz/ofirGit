# פרויקט חיפוש מלון זול

אפליקציית ווב פשוטה עם FastAPI הכוללת API וממשק סטטי למציאת המלון הזול ביותר לזוג לפי יעד ותאריכים.

## התקנה והרצה

1. יצירת סביבה וירטואלית והפעלתה:

```bash
python -m venv .venv
source .venv/bin/activate
```

2. התקנת תלויות:

```bash
pip install -r requirements.txt
```

3. הרצת השרת (כולל ממשק דוקס Swagger ב- `/docs`):

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

4. פתיחת הממשק הסטטי:

- גשו ל- `http://localhost:8000/` כדי לפתוח את הטופס.
- מסמכי API: `http://localhost:8000/docs`

## מבנה הפרויקט

```
app/
  main.py            # אפליקציית FastAPI והגדרת הראוטים
  models.py          # מודלים של Pydantic לבקשות/תגובות
  data/hotels.json   # דאטהסט פשוט של מלונות
  static/
    index.html       # עמוד HTML עם טופס
    app.js           # לוגיקת צד לקוח לקריאה ל-API
```

## הערות
- חישוב המחיר הכולל: מחיר ללילה לזוג כפול מספר הלילות.
- טיפול בשגיאות: יעד לא נמצא, תאריכים לא תקינים (כניסה אחרי יציאה או ללא לינות), ושדות חסרים.
